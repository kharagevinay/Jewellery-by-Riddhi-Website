JEWELLERY BY RIDDHI - RESPONSIVE STARTER

1. Extract the ZIP.
2. Open the jewellery-by-riddhi folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Edit css/style.css to change colours, spacing and responsive breakpoints.
5. Replace the images in assets/ with clean, high-resolution product photos.
6. In index.html, replace +910000000000 in tel: and wa.me links with the business number.

TECH:
- HTML5
- CSS3
- Bootstrap 5.3.3 (CDN)
- Small vanilla JavaScript file

Note: The included images are crops from the supplied screenshot for a quick prototype.
For production, use original logo and individual transparent product images.
